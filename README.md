# Java Practice Programs ☕

A collection of Java programs covering OOP concepts, graphics, exception handling, multithreading, and mini projects — written as part of Computer Engineering coursework at SPPU.

## 📁 Topics Covered

- **OOP** — Classes, Inheritance, Polymorphism, Object Methods
- **Exception Handling** — Try-catch, custom exceptions
- **Multithreading** — Thread creation and demo
- **Graphics** — Bresenham's Circle, Cohen-Sutherland Clipping, Polygon Fill
- **Mini Projects** — ATM Simulation, Quiz System, Number Guessing Game, Pattern Drawing

## 🛠️ How to Run

1. Open any `.java` file in VS Code or any Java IDE
2. Compile: `javac FileName.java`
3. Run: `java FileName`
